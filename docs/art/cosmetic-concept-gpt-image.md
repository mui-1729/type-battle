# GPT-Image コスメ原画

この原画は、ゲーム内SVGコスメの形・配色を検討するために、Codexの built-in GPT-Image で生成しました。

- 原画: `cosmetic-concept-gpt-image.png`
- 生成日: 2026-07-30
- 最終プロンプト要旨: 「2×2配置のゲーム用コスメ原画。紫で先端が曲がった魔法使いの帽子と金の星、白い翼の付いた金色の天使の輪、氷に覆われたマグロ剣、巨大な黄色い鉛筆剣。太いネイビー輪郭、明快なシルエット、文字なし。」

原画そのものはゲームへ直接表示せず、48px程度でも識別できるよう単純化したSVGとして `apps/web/app/_components/cosmetic-svg.tsx` に反映しています。コスメは見た目のみで、ゲーム性能には影響しません。
